# CN ONG research hub

Unofficial CohesionLab research draft based on the supplied one-page interface. Romanian content. No backend, payments, forms, analytics, or embedded third-party resources. `noindex` requests exclusion from search engines; it is not access control.

## Run and verify

Requires Node 24 and npm.

```sh
npm ci
npm test
npm run build
npm run preview -- --port 4173
```

Open http://127.0.0.1:4173/cn-ong-hub/ . The Vite base matches the proposed repository name `cn-ong-hub`.

## GitHub Pages

Public repository: `CohesionLab-org/cn-ong-hub`. Enable Pages with GitHub Actions as the source. The workflow tests and builds `main` before publishing. No custom domain is configured. The operator approved publishing this website code in a new public repository. No existing private repository is used.

## Content boundaries

Two linked publisher reports support the 2024 Forum and reported election of an 11-organization council for 2025–2026. The membership shortlist, historical timeline, legal status and Claca Civică proposal are explicitly unconfirmed. Six document titles from the source draft have no recovered original; their controls explain the gap instead of pretending to download PDFs. A contact address is attributed to the 2024 announcement and is not asserted to be current. Email opens the visitor's mail application and never sends automatically.

Research transcripts and the source attachment are not included. CN ONG approval of this draft is UNKNOWN.
